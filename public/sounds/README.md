# Dracula sound clips

The app plays a short cinematic sting when you switch to the Dracula theme:
lights go out, the organ and voice begin, the laugh follows, then bats cross the
screen and the editor is revealed. The pipe organ is always synthesized in the
browser. The recorded clips below are bundled with the project and used when
present; the app falls back to a synthesized laugh and bat chirps if they are
missing.

## Routing

The sting is routed to a chosen output device and never to Bluetooth headphones
such as the EH11. The first time it plays, if output labels are hidden, the
browser may ask which device to use; the choice is remembered. Use the speaker
button beside the theme switch to mute the effect.
